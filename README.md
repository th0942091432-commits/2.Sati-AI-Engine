# Sati-AI-Engine

## เกี่ยวกับ
ภาคปฏิบัติการของ Sati-AI: โครงสร้างโค้ด Python + สถาปัตยกรรม Verification Gate
สร้างขึ้นตามเอกสารแนวคิด Sati-AI-Concept

**สถานะ**: Abstract Class ต้นแบบ ยังไม่เคยรันกับ LLM จริง

## ไฟล์ใน Repo
- `sati_ai.py`: โครงหลัก Abstract Class
- `Sati-AI-Engine.pdf`: เอกสารสถาปัตยกรรม

## หลักการ 3 ขั้น
1.  **Sila First**: ตรวจอันตรายก่อน ถ้าอันตรายให้ปฏิเสธ
2.  **Passaddhi**: ตัด/ลดทอนข้อมูลที่ความมั่นใจต่ำ
3.  **Right Speech Gate**: กรองด้วยสัมมาวาจา 4
